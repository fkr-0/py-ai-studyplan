* Your learning track: 21 days on a MacBook Pro M4

- **Machine:** 2024 MacBook Pro, M4-family, 24 GB unified memory.

* 01 · What is AI doing?

Rule-based computation vs search/planning vs trained models.

- A Tetris advisor can use a *search algorithm*
- A neural network is a learned function
- An LLM predicts text tokens using trained parameters
- A fluent answer is not a correctness guarantee

** Inference is not training

#+begin_export html
<div class="study-flow">
<div><b>Training</b><small>examples → loss → gradients → updated weights</small></div>
<div><b>Inference</b><small>prompt → fixed weights → output tokens</small></div>
</div>
#+end_export

** Python first steps

#+begin_src python
def respond(message: str) -> str:
    text = message.lower().strip()
    if "hello" in text:
        return "Hello!"
    if text.endswith("?"):
        return "I don't know yet."
    return "Tell me more."

print(respond("Hello there"))
#+end_src

Independent change: detect three additional phrases.

You need a *model*, a *runtime/server*, and a *Python client*.

* 06 · Build a web interface

Streamlit makes a first browser UI possible without teaching JavaScript.

- =st.chat_input= · user question
- =st.chat_message= · display turns
- =st.session_state= · keep app state across reruns
- Python Ollama client · inference request
- Friendly offline/error messages

** Architecture

#+begin_example
Browser → Streamlit server → Ollama HTTP API
               │                  │
         chat history          model weights
               │                  │
         UI rendering ◀──── generated response
#+end_example

** Run your chatbot

#+begin_src sh
python -m pip install -r examples/requirements.txt

python -m streamlit run examples/chat_app.py

* 07 · Make it useful

- Structured output must be *parsed and validated*
- Models can make arithmetic/factual mistakes
- Treat model text as untrusted data
- Handle Ollama offline, missing models, and invalid responses
- Measure behavior with a tiny repeatable test set

** Evaluation exercise

| Input type | Test |
|-----------+------|
| Exact format | Is JSON parseable and schema-valid? |
| Arithmetic | Verify with ordinary Python |
| Summarization | Check facts against original |
| Failures | Stop Ollama and observe feedback |
| Compare models | Record model, settings, latency |

* 08 · Docker

Pack the *web UI* after it works locally.

- Dockerfile → reproducible image
- Container → process started from the image
- Ports → how the browser reaches the app
- Environment variables → configuration
- Compose → coordinate one or more services

** Build and launch (optional)

#+begin_src sh
docker build -t py-ai-studyplan-ui ./examples
docker compose -f examples/compose.yaml up --build
docker compose -f examples/compose.yaml down
#+end_src

Docker-internal =127.0.0.1= is *not* host-localhost. Keep Ollama private; the UI can demonstrate its offline fallback in a container.
