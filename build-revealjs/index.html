01 · What is AI doing?

Rule-based computation vs search/planning vs trained models.

  • A Tetris advisor can use a search algorithm
  • A neural network is a learned function
  • An LLM predicts text tokens using trained parameters
  • A fluent answer is not a correctness guarantee

Inference is not training

Trainingexamples → loss → gradients → updated weights
Inferenceprompt → fixed weights → output tokens

Discuss: Does changing temperature re-train the network? No.

Two key families (do not mix them)

⌘ Command — Mac application

⌘C copy selected terminal output

⌘V paste at shell prompt / in editor

⌘S save a file in VS Code

⌘T new Terminal.app tab

⌃ Control — zsh / running process

⌃A start · ⌃E end of command

⌃P previous · ⌃N next command

⌃R reverse history search

⌃C interrupt a running command

Learn ⌃A · ⌃E · ⌃P · ⌃N · ⌃R

In the zsh prompt Action
Control-A move cursor to start (A)
Control-E move cursor to end (E)
Control-P previous command (P)
Control-N next command (N)
Control-R reverse search in command history (R)

These act in the terminal shell prompt, not when VS Code's editor has focus.

Two-minute shortcut drill (no copying)

  1. Execute echo APPLES; then echo BANANAS.
  2. Hit ⌃P, again ⌃P, then ⌃N. What changed?
  3. Hit ⌃R, search APPLES, select it.
  4. Type echo hello there without Enter.
  5. Hit ⌃A then ⌃E; press Enter only at the end.

Perform live; keep the cursor visible. In default zsh Emacs-style line editing these bindings are standard. Optional plugins may remap them. Allow mistakes: use the arrow keys to recover, then try again.

Copy + paste is NOT Control-C

  • ⌘C copies selected terminal output; ⌘V pastes it.
  • ⌃C interrupts a program. Test: sleep 30 → ⌃C.
  • ⌃L clears the terminal; Tab attempts completion.
  • Select text with trackpad; copy into VS Code with ⌘C/⌘V.
  • Copy the command below into Terminal, inspect it, then press Enter.
printf 'Pasted safely into the terminal\n'

Never blindly paste multiline commands or run unknown curl | sh installers.

def respond(message: str) -> str:
    text = message.lower().strip()
    if "hello" in text:
        return "Hello!"
    if text.endswith("?"):
        return "I don't know yet."
    return "Tell me more."

print(respond("Hello there"))

Native zsh first; z4h is an optional extra

  • macOS already includes zsh — no framework required.
  • Zsh for Humans (z4h) ↗ works on macOS and adds autosuggestions, completions and fuzzy history.
  • Its maintainer states support is very limited; most bugs will go unfixed.
  • Its installer changes shell startup files (with backup prompts).
  • Do not install automatically or teach shell shortcuts through z4h first.

Introduce only after the Control-A/E/P/N/R drill and getting comfortable in stock zsh. Discuss tradeoffs, original README, backups, rollback. Do not pipe a remote script into a shell for a beginner.

05 · Local inference with Ollama

You need a model, a runtime/server, and a Python client.

Python (ollama client)
   │ HTTP /api/chat
   ▼
Ollama (inference runtime)
   │ loads quantized model weights
   ▼
Local model (CPU or GPU)

First Ollama call

cd ~/Projects/py-ai-studyplan
source .venv/bin/activate  # create .venv first if absent

# In another Terminal tab (⌘T):
cd ~/Projects/py-ai-studyplan
source .venv/bin/activate
python -m pip install -r examples/requirements.txt
python examples/cli_chat.py --model gemma3:4b

Your Mac M4 · 24 GB unified memory

  • Compare with qwen3:8b later (optional).

06 · Build a web interface

Streamlit makes a first browser UI possible without teaching JavaScript.

  • st.chat_input · user question
  • st.chat_message · display turns
  • st.session_state · keep app state across reruns
  • Python Ollama client · inference request
  • Friendly offline/error messages

Architecture

Browser → Streamlit server → Ollama HTTP API
               │                  │
         chat history          model weights
               │                  │
         UI rendering ◀──── generated response

Run your chatbot

cd ~/Projects/py-ai-studyplan
source .venv/bin/activate
python -m pip install -r examples/requirements.txt
# Ollama desktop app is already running and model pulled.
python -m streamlit run examples/chat_app.py --server.address 127.0.0.1

Observe: when you stop Ollama, Python can still display the web UI but cannot serve model completions.

08 · Docker

Pack the web UI after it works locally.

  • Dockerfile → reproducible image
  • Container → process started from the image
  • Ports → how the browser reaches the app
  • Environment variables → configuration
  • Compose → coordinate one or more services

Build and launch (optional)

docker build -t py-ai-studyplan-ui ./examples
docker compose -f examples/compose.yaml up --build
