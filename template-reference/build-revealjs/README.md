# Terminal Power deck

Canonical deck directory for this project.

- Open `index.html` in a browser.
- Edit `source.org` as the source of truth.
- Keep custom styles in `assets/tomorrow-night-terminal.css`.

Presenter keys:

- `S`: speaker notes
- `F`: fullscreen in many browsers
- `B`: whiteboard / chalkboard mode
- `C`: slide annotation canvas
- `DEL`: clear current drawing
- `/`: search
- `Alt` + click: zoom plugin
