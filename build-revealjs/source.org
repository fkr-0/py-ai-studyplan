* 01 · What is AI doing?

Rule-based computation vs search/planning vs trained models.

- A Tetris advisor can use a *search algorithm*
- A neural network is a learned function
- An LLM predicts text tokens using trained parameters
- A fluent answer is not a correctness guarantee

** Mini-exercise: where does my question go?

*Imagine asking a chatbot:* /“Why is the sky blue?”/

Put these three cards in order. You can point or say the answer — **no drawing or coding necessary**:

- *You* — type the question.
- *Chat app* — shows messages on screen and sends the question onward.
- *Language model* — generates a possible answer.

**Try:** Which card is first? Which card makes the words? Which card displays them?

#+BEGIN_NOTES
Pause and let the beginner order the three cards orally. Do not require knowledge of Python or Ollama yet. Say that this is a simplified view. Show the answer on the next slide and briefly introduce the model server there.
#+END_NOTES

** Example answer: follow one message

#+begin_example
YOU          CHAT APP             LANGUAGE MODEL
  |  question   |                      |
  +-----------> | --- question ------> |
                | <-- answer --------- |
  <------------ +                      |
     see reply
#+end_example

- *Your action:* type “Why is the sky blue?”
- *Chat app:* sends it and displays the returned text.
- *Model:* produces a plausible explanation, which may need checking.
- *Later:* we will learn about **Ollama**, the program that runs the model on your Mac.

**Bonus question:** A simple rule-based chatbot could replace the model with =if= statements. How would its answers differ?

** Two-minute shortcut drill (no copying)

1. Execute =echo APPLES=; then =echo BANANAS=.
2. Hit *⌃P*, again *⌃P*, then *⌃N*. What changed?
3. Hit *⌃R*, search =APPLES=, select it.
4. Type =echo hello there= *without Enter*.
5. Hit *⌃A* then *⌃E*; press Enter only at the end.

#+BEGIN_NOTES
Perform live; keep the cursor visible. In default zsh Emacs-style line editing these bindings are standard. Optional plugins may remap them. Allow mistakes: use the arrow keys to recover, then try again.
#+END_NOTES

** Copy + paste is NOT Control-C

- *⌘C* copies selected terminal output; *⌘V* pastes it.
- *⌃C* interrupts a program. Test: =sleep 30= → ⌃C.
- *⌃L* clears the terminal; *Tab* attempts completion.
- Select text with trackpad; copy into VS Code with ⌘C/⌘V.
- Copy the command below into Terminal, *inspect it*, then press Enter.

#+begin_src sh
printf 'Pasted safely into the terminal\n'
#+end_src

*Never blindly paste multiline commands or run unknown =curl | sh= installers.*

- Fail gracefully if model is unavailable
- Reproduce setup from the README

** Project B · Classical Tetris AI (optional)

1. Represent a board and valid piece placements
2. Score lines, holes, height and bumpiness
3. Search legal placements and choose a move
4. Compare to random moves on fixed seeds
5. Optional LLM explains the chosen move

A Tetris *solver* is primarily a search/planning lesson. Do not imply that an LLM inherently solves Tetris.
